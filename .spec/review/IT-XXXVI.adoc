== Delivered

- `SnowballProgram`: the runtime base. Buffer and slice marks, a backward
  lower bound, forward and backward equality, grouped characters, ranges,
  forward and backward among tables with longest-match selection, slice
  replacement, deletion, insertion, slice validation and cursor movement.
- `Among`: an among-table entry with its text, shared-substring hint and
  result value.
- `Stem`: the language registry. `of`, `availableLanguages`, `isAvailable`,
  `stem` and `name`; `none` selects the identity stemmer; an unknown name
  raises `InvalidArgumentError`. It implements `termgen.Stemmer`, so a
  `TermGenerator` accepts it directly.
- `PorterStemmer`: the Porter algorithm in steps 1a to 5b with the measure
  and consonant rules; registered under `porter`.
- Tests: 18 runtime tests against the primitives and 83 Porter and
  registry tests, 101 in total.
- Commit `4eb9684`.

== Deviations

- The plan asks for the runtime of the reference generator and its
  dispatch tables. The reference sources and the `.sbl` algorithms are not
  present in this environment, so the runtime is written from the Snowball
  algorithm contract and the among tables are read without the
  shared-substring fast path; correctness does not depend on the hint.
- The only shipped algorithm is Porter, which is implemented directly
  rather than generated from `.sbl`. The 39 reference algorithms are ID-36.
- No reference executable is available, so parity with the C++ stemmer is
  unverified. The Porter vectors are the published ones, not reference
  output.
- Per-language stop-word lists are not part of the reference language
  directory; `termgen.Stopper` carries the only list machinery.
- `mvn verify -Ppitest` remains unverified since CQ-IV; the new package is
  covered by 101 tests but its mutation score is unmeasured.
