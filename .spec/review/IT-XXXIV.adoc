== Delivered

- `QueryParser`: recursive descent over the token stream. Precedence from
  lowest to highest: OR, AND and AND_NOT, NEAR, phrase, term. Implicit
  combinations take the selected default operator; a difference applies to
  the accumulated conjunction; a conjunction stays flat.
- `QueryParserToken`: sealed token hierarchy with term, phrase, operator,
  field, wildcard, range, group and end-of-input tokens. A phrase carries
  a list of words; a range carries both bound kinds and the closing bracket.
- `QueryParserTokeniser`: terms, quoted phrases with backslash escapes,
  boolean keywords in upper case only, `+`, `-`, `~` with an optional
  distance, wildcard patterns, inclusive and exclusive ranges, field values
  and `slot:[a TO b]` value ranges. An unclosed phrase, an unclosed range
  and a range without `TO` are rejected.
- Commit `6149d47`.
