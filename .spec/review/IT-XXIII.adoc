== Delivered

- `PhrasePostList`: ordered phrase match within an inclusive position
  span, with overflow guards and a minimum-wdf estimate.
- `ExactPhrasePostList`: adjacent-position phrase match.
- `NearPostList`: unordered window match that requires distinct positions
  for repeated terms and rejects empty position lists.
- `OrPositionList`: sorted unique union of position lists with lazy
  `next`/`skipTo` movement.
- `OrPosPostList`: positional wrapper over a disjunction that supplies
  merged positions and forwards weights and estimates.
- `SelectPostList` and `SelectSetup`/`OrPosSetup`/`OrPositionSetup`
  scaffolding for filtered streams and validated setup.
- Tests: `PhraseNearPostListTest`, `OrPositionListTest`,
  `SelectPostListTest`, plus a brute-force `PositionalOracle` and a
  deterministic `PositionalTestData`. The phrase/near tests include a
  translated reference regression vector (inclusive window edge) and a
  direction-sensitive ordering vector; a first attempt with a
  contaminating term in the second document failed and was corrected, not
  worked around.
- `BooleanPostListFixtureFake.readPositionList` so boolean fixtures can
  act as positional leaves.

== Deviations

- Reference executables and command-line tools remain unavailable by the
  accepted artefact policy. Window semantics were checked against the
  reference sources (`phrasepostlist.cc`, `nearpostlist.cc`,
  `exactphrasepostlist.cc`, `orpositionlist.cc`, `selectpostlist.cc`) and
  against source-derived vectors and the brute-force positional model,
  not against a live same-database run.
- The positional oracle is structurally close to the production matcher
  for phrase matching (both walk base positions and skip each following
  term), so it is a regression oracle rather than an independent one.
- The Java operators re-read position lists per candidate base position,
  while the reference caches lists and advances a high-water mark. Near
  matching additionally materialises every position and backtracks over
  candidate windows. Results agree on covered vectors; cost is a known
  gap tracked by ID-49, not a correctness deviation.
