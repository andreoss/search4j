== Delivered

- `PL2Weight`: PL2 weight scheme with configurable c parameter (default 1.0).
  Uses Laplace after-effect with Poisson approximation.
- `PL2PlusWeight`: PL2+ weight scheme with configurable c and delta parameters
  (defaults 1.0, 1.0). Adds saturation control to PL2.
- `IneB2Weight`: Inverse Expected Document Frequency B2 variant.
  Uses inverse expected IDF with B2 after-effect.
- `IfB2Weight`: Inverse Document Frequency B2 variant.
  Uses standard IDF with B2 after-effect.
- `InL2Weight`: Inverse Document Frequency L2 variant.
  Uses standard IDF with L2 after-effect (full length normalisation).
- `DPHWeight`: Divergence from Randomness with Hypergeometric after-effect.
  Uses DPH normalised WDF with hypergeometric correction.
- `DLHWeight`: Divergence from Randomness with Hellinger after-effect.
  Uses DLH normalised WDF with Hellinger distance correction.
- `BB2Weight`: Bose-Einstein statistics B2 variant.
  Uses Bose-Einstein IDF with B2 after-effect.
- All weights integrated with `WeightInternal` for serialisation/deserialisation.
- All use `WeightNorms` utility for IDF/WDF normalisation functions.
