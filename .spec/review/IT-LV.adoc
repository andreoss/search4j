== Delivered

- `Registry`: named factories of weighting schemes and range processors,
  case-insensitive names, the fifteen shipped schemes registered by
  default, custom registration, lookup and listing.
- `RSet`: relevance set in ascending document order with add, remove,
  membership, size, clear and description.
- `TermInfo`: term frequency, collection frequency and maximum
  within-document frequency with the reference description text.
- `SmallVector`: growable integer vector with doubling capacity, bounds
  checks and array copy.
- `VectorTermList`: term iterator over a fixed word list with frequency
  one, no positions and skip-to.
- `RangeProcessor` and `ValueRangeProcessor`: range text to a value range
  query over a slot.
- `ValueSetMatchDecider`: accepts documents whose slot value belongs to a
  set, with an inverted mode.
- `EditDistance`, `KeyMaker`, `MatchSpy` and the sortable serialisation
  already existed and were not duplicated.
- 23 tests in `RemainingApiTest`.
- Commit `2c49eca`.

== Deviations

- `Registry` registers weighting schemes and range processors only. The
  reference registry also registers posting sources; this build has no
  public posting-source factory to register.
- `ValueSetMatchDecider` decides on a document identifier and reads the
  value through a shard, because the local `MatchDecider` contract takes a
  document identifier rather than a document.
- `VectorTermList` reports a term frequency of zero and no positions; the
  reference list is a synthetic document term list with the same limits.
- No reference executable is available, so the description texts and the
  registry defaults are source-derived.
- `mvn verify -Ppitest` remains unverified since CQ-IV.
